📊 Project Overview

This project is an **Excel-based Retail Sales Data Analysis and Dashboard project** created to analyze 100,000 retail transaction records and generate meaningful business insights.

The project demonstrates the complete data analyst workflow in Excel, including data organization, analysis using PivotTables, KPI analysis, and interactive dashboard creation.


 ---
 🎯 Project Objectives

* Analyze retail sales performance
* Understand sales and profit trends
* Analyze product and category performance
* Examine customer demographics
* Compare sales across regions and states
* Analyze payment modes and sales channels
* Identify sales and profit patterns
* Create an interactive Excel dashboard
* Present business insights using charts and KPIs

---

## 📁 Excel Workbook Structure

### `Retail_Data`

Main retail transaction dataset containing 100,000 records.

### `Product_Master`

Contains product-level master information:

* Product ID
* Product Name
* Category
* Sub-Category
* Unit Price
* Unit Cost

### `State_Master`

Contains state-related master information used for geographical analysis.

### `pivot table`

Contains PivotTable-based analysis of:

* Sales
* Cost
* Profit
* Quantity
* Product information

### `DASHBOARD`

Interactive Excel dashboard containing KPIs, charts, and filters for analyzing retail performance.

## 🚀 How to Use

1. Download the Excel workbook.
2. Open `retail_project(1).xlsx` using Microsoft Excel.
3. Navigate to the `DASHBOARD` sheet.
4. Use the available slicers and filters.
5. Explore the `pivot table` sheet for supporting analysis.
6. Use the `Retail_Data` sheet to examine the underlying transaction data.
